# Notas sobre trabalhar como autônomo

- Para caracterizar trabalho autônomo, a "empresa" deverá ter o nome da pessoa física, exemplo: "Maria Aparecida de Souza", caso contrário é necessário um registro e o recolhimento dos impostos (TPS, TVQ).
- Tenha uma conta bancária exclusiva para o negócio
- Todas as despesas devem ser registradas
	- Crie uma planilha para facilitar
	- Os recibos precisam ser guardados por 5 anos, eles podem ser digitalizados (se o governo solicitar, será a versão digitalizada)
- Somente após 30.000 em receita nos últimos 12 meses passa a ser obrigatório o registro da empresa para recolhimento de imposto.
	- O recolhimento é obrigatório após esse valor, caso as vendas estejam próximas dele com perspectiva a alcançar, sugere-se que se faça o registro para evitar multas
	- Após o registro feito, todas as vendas seguintes serão tributadas (TPS, TVQ)
- As despesas com o negócio podem ser deduzidas no Revenu, para isso todos os recibos precisam ter sido guardados, a planilha ajuda nessa organização
- No geral, as pessoas pagam no crédito, é conveniente comprar uma máquina para poder receber em crédito
	- Existem opções online, o `square` por exemplo, nesse caso se usa o celular como máquina de aproximação
	- O `square` também permite a criação de uma "venda online", mas a entrega não é simples, porém, utilizá-lo como "vitrine" pode ser uma boa opção.
