# Objective  

Criar um serviço responsável por persistir os dados de conexão de banco de dados.

# Context  

- Salvar, no arquivo de JSON, a estrutura necessária para conexão com o banco SQL Server
- Os dados a serem salvos serão:
	- Servidor
	- Database
	- Usuário
	- Senha
	- Se utiliza ou não autenticação do Windows

# Requirements  

# Constraints  

- Todos os dados são obrigatórios

# Deliverables  

1. Teste de unidade da estrutura
2. Todo o código e possíveis comentários deve estar em inglês

# Success Criteria  

- O usuário ser capaz de salvar os dados via API
- O sistema ter teste unitário para a nova estrutura
