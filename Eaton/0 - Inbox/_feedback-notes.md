## Espaço para melhorar

- Os documentos gerados (DDS e Data Mapping) não tem as informações necessárias para que o desenvolvedor possa realizar o trabalho.
	- As propriedades do documento não tem os mesmos nomes das propriedades do CYMDist
	- O nome das tabelas no documento não representam o CYMDist, em vários casos uma mesma feature alimenta mais de uma tabela no CYMDist.
	- As condições no documento não são claras
		- O estilo de escrita é confuso
		- Tem situações como `CAMPO_1 = Operacional`, porém o valor na base de dados do cliente é número e não se tem uma tabela de conversão.
	- Alguns objetos CYMDist requerem um "Tipo de Dispositivo", que talvez seja claro para os profissionais mais antigos, mas que não é fácil de identificar por mim.
	- Tenho o sentimento que os documentos não indicam todos os campos que devem ser preenchidos e que o desenvolver deve saber todos eles.
- O sistema utiliza versões antigas de bibliotecas e não vejo uma iniciativa de modernização
- Apesar de o relacionamento entre os integrantes do time ser bom, tenho a sensação de muita individualidade, poucos são os que realmente interagem e auxiliam uns aos outros diretamente (tenho uma ótima experiência com o Brice, Joanne, Basile e Jean Sebastien).
