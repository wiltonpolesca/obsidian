## Docker / Podman

**Importante:** 
Não existe diferença no uso do Docker ou Podman, o funcionamento dos dois é o mesmo, a diferença é apenas que o Docker Desktop (para windows) não é gratuito enquanto o Podman é 100% gratuito.

Para o uso no dia a dia, apenas alteramos o comando inicial, no lugar de iniciar o comando como `docker`, utilizamos `podman` ex:

| Docker        | Podman        |                                                      |
| ------------- | ------------- | ---------------------------------------------------- |
| **docker** ps | **podman** ps | Lista as imagens (pods ou imagens) em execução agora |

Em resumo, tudo aquilo que você aprender como `docker` funciona da mesma forma como `podman`.
