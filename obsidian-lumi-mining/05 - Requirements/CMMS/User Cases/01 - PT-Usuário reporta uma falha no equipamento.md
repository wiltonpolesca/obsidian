# 01 - Operador reportar falha no equipamento ao CCO e CCO reporta a equipe de manutenção

1. Operador identificado reporta ao CCO uma falha no equipamento
2. CCO solicita informações sobre a falha
3. Operador notifica
	1. Local do equipamento
	2. Problema encontrado
		1. Necessita de assitência no local ou se o equipamento se move?
4. CCO toma decisão de acordo com o relato do operador
	1. Equipamento se move (opções disponíveis)
	    a) CCO indica local de destino para onde o operador deverá conduzir o equipamento.
	    b) CCO solicita transporte (caso necessário) para o operador e orienta a deixar o veículo onde está, seguindo todos os protocolos de segurança
	2. Falha impede o equipamento de se locomover
		1.  CCO solicita transporte (caso necessário) para o operador e orienta a deixar o veículo onde está, seguindo todos os protocolos de segurança
5. CCO Abre chamado na equipe de manutenção para atendimento ao equipamento com falha
6. Equipe de manutenção solicita:
	1. Criticidade no atendimento
	2. Equipamento
	3. Operador que relatou o problema
	4. Horímetro do equipamento
	5. Local atual do equipamento
	6. Descrição do problema
