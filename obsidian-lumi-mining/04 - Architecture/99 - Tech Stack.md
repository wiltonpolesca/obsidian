# Teck stack

## Frontend & Client Applications

- **Mobile Apps:** To be defined (flutter, Kotlin, ?)
- **Web Application:** Angular, Angular Material, Tailwind, Transloco
- **API & Communication:** Rest Api and NATS for asynchronous event-driven communication between microservices.

## Backend & Microservices

- **Core Frameworks:** C# .net 
- **Routing & Load Balancing:** Traefik
- **Authentication:** Keycloak

## Databases & Caching

- **Distributed SQL:** PostgreSQL
- **Time series:** Tiger Data (former TimescaleDB)
- **Caching:** Redis

## Streaming

- **Streaming & Messaging:** NATS (maybe Kafka in the future).

## DevOps, CI/CD & Cloud Infrastructure

- **Cloud Platform:** Must be cloud agnostic
- **Deployment & Orchestration:** Docker (Podman) compose
- **Monitoring & Tracking:** To be defined (maybe Jira, and Confluence).
